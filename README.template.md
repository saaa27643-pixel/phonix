# Phoenix v10.0 – C2 Framework (Advanced Stealth)

**Make your Hacktoberfest forges to a full-fledged hackathon like give us a chance to contribute to the open-source community.**

## Features
- Polymorphic payloads (morphs every request)
- Stealth network communication (SSE + Jitter + Adaptive Compression)
- Bypass camera indicators (iOS/Android)
- Persistent via PWA + Web Locks + FedCM
- Telegram integration with automatic file chunking (>2GB)
- Tor support for server anonymity
- AI-powered smart commands (face detection)

## Quick Start
1. Copy `.env.example` to `.env` and fill tokens.
2. Run `npm install` in `/backend`.
3. Run `node server.js`.
4. Deploy `/frontend` to any static host.
